Build a complete, production-quality corporate website for Trevia EV Technologies.

Trevia is an EV charging digital infrastructure/software company.

The website must position Trevia as the software and operating layer between EV charging hardware and the organizations operating charging infrastructure.

Trevia is NOT:

a charger hardware manufacturer

a generic EV consumer app company

a single-sided CPO

a futuristic EV lifestyle brand

The primary commercial product is:

Trevia CMS

Primary positioning:

“The operating layer for your charging network.”

NOT:
